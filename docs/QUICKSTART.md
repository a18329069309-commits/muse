# 第一次运行 W自动配乐

本页的目标是在没有账户、私人配置、商业素材或模型服务的情况下，复现一个范围清楚的离线渲染演示。它不是新影片自动分析、选曲或听感通过的展示。

## 1. 准备依赖

单独安装 Node.js 24.19.0+（24.x）、FFmpeg 和 ffprobe，并确保终端能够找到它们。本仓库不分发这些工具的二进制，也不会替你安装或下载。离线演示不需要 Python、npm 依赖安装、API 密钥或订阅登录。

先从公开仓库获取源码并进入目录：

```sh
git clone https://github.com/a18329069309-commits/w-auto-score.git
cd w-auto-score
node tools/doctor.mjs
```

`doctor` 只检查本地能力，不调用模型、不创建任务、不写入授权或听审记录。它会区分“离线演示可运行”和“完整自动模式未验证”。输出 JSON 可使用 `node tools/doctor.mjs --json`。Python 缺失不阻断这份离线演示。

如果提示找不到 FFmpeg 或 ffprobe，请确认两者都已安装并加入 PATH，重新打开终端后再检查。若检测到版本或所需能力不符，先按诊断提示修复；不要通过删除安全校验来消除错误。

## 2. 运行固定编排演示

```sh
node tools/demo-offline.mjs
```

默认顺序处理两段合成片段。只运行单片：

```sh
node tools/demo-offline.mjs --episodes 1
```

所有画面和测试声音在本地生成，不下载影视、歌曲、模型或音效库。演示调用项目已有的 `renderPlan` 渲染器，不使用另一套替代混音算法。输出包括可播放的预览、与画面同长的分轨及描述本次执行范围的 JSON 报告。报告中的技术通过不等于艺术或听感通过。

命令结束时会打印实际输出目录，默认内容结构为：

```text
demo-report.json
episode-01/
  preview.mp4
  final-mix.wav
  episode-report.json
  render/
    bgm.wav
    sfx.wav
    ambience.wav
    accompaniment.wav
episode-02/
  ...
```

双击 `preview.mp4` 可查看三秒技术预览。颜色切换位置有一个合成音效，另有合成音调代理的避让区间，用来验证时间轴和混音；这些不是原创配乐作品，也不是真人对白。根报告汇总每片成功或失败，单片报告包含文件哈希、实际解码时长、峰值、避让和画面切换的技术测量。

默认输出保存在项目 `.muse/` 中的新目录，不写入全局运行环境，也不接续已有用户任务。自定义目录时，父目录须已存在，末级目录必须尚不存在；工具不创建自定义父目录：

```sh
node tools/demo-offline.mjs --episodes 2 --out .muse/my-first-demo
```

已有目录不会被覆盖，重跑时请另选新目录。发生失败时保留执行现场；不要把未成功的片段算作通过。演示的批次行为仅涵盖这些固定合成案例，不是生产上传入口、真实选材或持久任务恢复的端到端验收。

为保护工作目录，这个入口拒绝向 Windows C 盘、文件系统根目录或项目根目录输出；指向 C 盘的目录链接也会被拒绝。在其他目录使用源码时，请选择符合该限制的工作位置。缺 FFmpeg、输入参数错误或任一片段失败时，命令返回非零退出码。检查 `demo-report.json` 中的逐片状态；出现 `failed` 时先排查本地工具，再使用一个全新目录重试。不要删除门禁或把失败记录手工改为成功。

演示和测试使用 Node 层网络拦截，并清理继承的模型相关环境变量。这不是操作系统级禁网沙箱，不保证能阻止任意外部程序联网；演示只启动已列明的本地媒体工具，不启动模型、账户或下载程序。

## 3. 运行离线回归

```sh
node tools/check-public.mjs
node tools/test-offline.mjs
```

测试日志和汇总保存在项目 `.muse/`。包含真实 FFmpeg 合成媒体的渲染验证，以及无效输入、缺依赖、输出保护和失败隔离检查。跳过项单独报告，不算通过；具体实际结果见 [验证记录](VALIDATION.md)。

## 4. 带自己的影片进入完整自动模式

先读 [部署说明](DEPLOYMENT.md)。真实模式还需要获准素材库、可用宿主或模型能力、预算策略、与实际文件对应的证据绑定，以及听审工具和真实资格；这份演示不会替你伪造它们。

如果已经有自己准备的真实部署配置，可以先做只读检查：

```sh
node tools/doctor.mjs --profile ABSOLUTE_DEPLOYMENT_JSON --json
```

该步骤只检查所提供文件的本地结构和绑定，不启动自动配乐、上传影片、执行推理或验证听感。即使配置校验通过，也不代表运行时、曲库权利、完整资格和真实任务已通过。请不要公开配置文件、机器路径、账户或素材库。

## 开源实现与素材来源

实现先复用了本仓库已有渲染入口和 [FFmpeg 开源项目](https://github.com/FFmpeg/FFmpeg)。生成测试信号的用法参考 [FFmpeg 官方滤镜文档](https://ffmpeg.org/ffmpeg-filters.html)，没有引入额外的 FFmpeg 包装依赖、第三方影视或歌曲。依赖工具许可取决于实际安装的构建，见 [第三方说明](../THIRD_PARTY_NOTICES.md)。
