# 维护路线图

- 已准备：个人署名、独立公开源码快照、第三方声明、无账户离线测试入口。
- 已有接口（preview.3）：新独立部署的听审配置绑定、标准 API 的冻结音画请求与回执契约、多模态规划预算、严格两阶段预检及本片预算隔离、兼容 FFmpeg 6.1 的证据窗口。实际工程验证范围见 [验证记录](VALIDATION.md)。
- 本轮（preview.4）：D 盘 Windows PowerShell 首次使用与 Git／源码 ZIP 两条路线、仅当前终端的依赖 PATH 说明、离线演示错误的固定恢复指引、报告字段解释及脱敏问题模板；不扩展配乐算法。仅以本轮实际执行结果更新验证记录，不将文档步骤视为全新电脑安装验收。
- 首要待办：合规真实演示素材、真实服务及资格准备；在干净环境验证新独立部署的真实新片单集与批量处理。合成演示和隔离 transport 测试不算作这些任务已完成。
- 持续改进：多题材选材、情绪转折、换曲衔接、可闻音效、对白避让和失败恢复。
- 独立验收：自动听审、受限返修、运行时兼容、素材许可与实际成片听感。
- 后续按需求考虑桌面界面，不以新 UI 代替配乐核心验证。

仅根据真实问题更新，不为申请制造版本或采用量。历史局部好评保留其具体范围；不发布无来源的统一成功率、耗时或产能保证。
